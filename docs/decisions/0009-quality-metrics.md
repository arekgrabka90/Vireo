# 0009 — Metodologia metryk

**Status:** Wymagania zatwierdzone. Konkretne urządzenia referencyjne czekają na wskazanie przez właściciela. Specyfikacja: `../specs/quality-metrics.md`.

- Kryteria wydajności wskazują urządzenie referencyjne, liczbę prób i narzędzia.
- Wydajność aplikacji jest oddzielona od jakości sieci i dostawcy IPTV (lokalny serwer testowy).
- Dla TMDB osobno mierzymy precyzję automatycznych dopasowań i pokrycie katalogu.
